# AegisBrush 溯源算法与区块标注 GUI 开发经验

> 项目：E:\Python-Project\AegisBrush（OC 作品防盗用 + 反 AI 训练水印工具）
> 本文沉淀「盗图溯源」从全图特征匹配升级到「结构+颜色双重校验 + 用户标注关键花纹区块加强比较」的完整经验，以及配套 CustomTkinter 标注窗口的交互与布局坑。

## 1. ORB 灰度特征的盲区：同线稿不同上色会被误判盗用

**问题**：ORB 是灰度特征，只看线稿/轮廓。`兽设模板上色版.png` 与 `格雷福斯.png` 基于同一线稿模板但配色/花纹不同，ORB+RANSAC 内点率高达 0.4+，被误判为「同源盗图」。

**解决**：feature 模式增加「内点局部颜色一致性」校验——对每个 RANSAC 内点，取两图对应位置 5×5 patch 的**中位数颜色**转 Lab 空间算距离，一致率 = Lab<30 的内点占比。

**实测数据（真实文件）**：

| 场景 | 内点率 | 颜色一致率 | 判定 |
|---|---|---|---|
| 加噪盗图 | 0.999 | 0.98 | 同源盗图 |
| 裁剪盗图 | 0.98 | 0.81 | 同源盗图 |
| 同线稿不同上色 | 0.42 | **0.47** | 不算盗用 |

**阈值**：结构匹配（内点≥15 且内点率≥0.3）**且** 颜色匹配（一致率≥0.70 且 Lab 中位数≤25）才判盗图。

**坑**：全局 HSV 颜色直方图对加噪图不可靠（噪声把直方图抹平，correl 仅 0.30），必须用 patch 中位数/分位数颜色。

## 2. 关键花纹区块加强比较（用户标注，只标原图）

**设计**：用户在原图上框选独特花纹区块（头部/胸/手臂/大腿），溯源时逐块比对。**只标原图即可**——算法用单应矩阵自动把区块映射到疑似图对应位置，比手工两边标注更准（疑似图有几何变换时手工标对不齐）。

**三步算法**：

1. **对齐**：ORB+RANSAC 估计原图→疑似图单应矩阵。大图性能优化：缩放到 max_side=1000 匹配，再坐标换算回原始像素：`H_orig = diag(1/sb,1/sb,1) · H_small · diag(sa,sa,1)`（sa/sb 为两图缩放系数）。
2. **warp**：`cv2.warpPerspective(原图, H_orig, 疑似图尺寸)`，使两图视角对齐。
3. **逐块比较**：同一坐标裁 patch，算「局部 ORB 图案内点率」+「分位 Lab 颜色相似度」。

**命中阈值**：pattern_ratio ≥ 0.85 且 color_sim ≥ 0.5。

**实测数据**：真盗图 pattern≈0.99（连花纹细节都对得上），同线稿不同上色 pattern 0~0.65——**图案匹配率是最强区分信号**（两图即使同属青蓝白色系，花纹细节不同）。

## 3. 边界：整体去色盗图

高饱和图整体转黑白会丢失颜色信息，feature 会判「不同上色」（漏报）。兜底：同时跑 phash/dhash（对灰度鲁棒，距离 0）。GUI 里 feature 判「同结构不同上色」但 pHash≤5 时，追加提示「疑似整体去色/调色盗图」。

## 4. CustomTkinter 标注窗口交互

- **缩放+平移复用灯箱逻辑**：滚轮以鼠标为锚缩放、Ctrl+左键平移。区分事件：`event.state & 0x0004` 判断 Ctrl 按下 → 平移，否则左键拖拽画框。
- **缩放后坐标换算**：原始像素 = (canvas坐标 − offset) / scale。缩放/平移只改显示，区块存原始坐标，重绘时乘回 scale。
- **重开回填**：构造参数 `initial_regions` 深拷贝载入上次标注，画布框/表格/列表三处同步恢复。
- **取消不添加**：`CTkInputDialog.get_input()` 点「取消」返回 `None`、留空返回空串，必须 `if name is None: return` 区分，否则取消也会误加区块。
- **表格**：CustomTkinter 无原生表格，用 `ttk.Treeview`（`from tkinter import ttk`），`style.theme_use('clam')` + 自定义深色配色适配暗色主题。

## 5. GUI 布局自适应（最大化不混乱）

- **grid 列 weight**：标题列 `weight=0`（自适应内容宽）、进度条列 `weight=1`（占满剩余），避免两列都 weight=1 导致「标题和进度条各占一半、中间大空档」。
- **动态换行**：固定 `wraplength` 会让长文本在窗口变大后仍缩在窄条；绑定 `<Configure>` 事件，把 `wraplength` 实时设为 `面板宽度 - 30`。

## 6. DSH 环境陷阱（本次再次踩到）

- JS 模板字符串里的 `\n` 会变成**真实换行**，破坏 Python 字符串字面量 → 跨行字符串用单行写法或隐式拼接。
- `write`/`edit` 报 `file changed since read` → 同一 `run_code` 内先 `read` 再写。
- `ReplaceFileW EIO (Win32 1175)` 是瞬时错误 → 重试几次即可。
- 删除后的文件再 `write` 报 `file no longer exists` → 换新文件名。
- Windows 控制台 GBK 显示中文乱码：脚本内 `sys.stdout.reconfigure(encoding='utf-8')`。
